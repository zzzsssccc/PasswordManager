# 🔐 安全密码生成器

一个现代化、功能强大的密码生成器网站，帮助您创建安全、难以破解的强密码。

## ✨ 功能特点

### 🔒 高安全性
- 使用 Web Crypto API 生成真正的随机密码
- 支持多种字符类型：大写字母、小写字母、数字、特殊字符
- 可排除相似字符（l, 1, I, O, 0）避免混淆
- 密码长度可调节（4-64位）

### 🎨 现代化 UI 设计
- 简洁直观的用户界面
- 明暗主题切换
- 响应式设计，完美适配桌面和移动设备
- 流畅的动画和过渡效果

### 📊 密码强度评估
- 实时密码强度检测
- 视觉化的强度指示器
- 从"弱"到"强"的多级评估

### 📝 实用功能
- 一键复制密码到剪贴板
- 密码历史记录（自动保存最近10条）
- 键盘快捷键支持
- 本地存储保护隐私

## 🚀 使用方法

### 在线使用
直接在浏览器中打开 `index.html` 文件即可使用。

### 本地运行
```bash
# 使用任意静态文件服务器
npx serve .
# 或者
python -m http.server 8000
```

## ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Enter` | 生成新密码 |
| `Ctrl/Cmd + C` | 复制当前密码 |
| `Ctrl/Cmd + Shift + T` | 切换主题 |

## 🎯 密码强度评估标准

- **弱 (0-40%)**: 短密码或字符类型单一
- **一般 (40-60%)**: 基础长度，2-3种字符类型
- **良好 (60-80%)**: 较长密码，3种以上字符类型
- **强 (80-100%)**: 16位以上，包含所有字符类型

## 🔒 隐私安全

- ✅ 所有密码在本地生成，不发送到任何服务器
- ✅ 使用浏览器 Web Crypto API 保证随机性
- ✅ 密码历史仅保存在本地 localStorage
- ✅ 完全离线可用
